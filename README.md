# 小银子

一个以本地播放为核心的 Android 音乐播放器，使用 Kotlin、Jetpack Compose 与 AndroidX Media3。

## 已实现

- 首次启动自动创建应用专属 `xiaozi` 音乐目录
- 通过系统文件选择器导入包含 MP3、LRC、LRCX 的 ZIP 压缩包
- 可从歌曲菜单永久删除音乐文件及其关联歌词
- 内置银临专辑分组，缺少本地文件的专辑曲目会置灰显示；长按预设分组可删除并恢复
- 右侧功能栏统一提供音乐导入、重新扫描、Mac 实时歌词与预设分组恢复
- 递归扫描 MP3、M4A、AAC、FLAC、WAV、OGG、OPUS
- 读取歌曲标题、音乐人、专辑与时长
- Room 本地资料库，可创建/删除分组、把歌曲加入或移出分组
- Media3 `MediaSessionService` 后台播放
- 系统媒体通知、锁屏控制和蓝牙耳机播放/暂停/切歌
- 顺序队列、随机播放、列表循环、单曲循环
- 同目录、同文件名 `.lrc` / `.lrcx` 歌词匹配
- 播放详情默认展示旋转唱片，轻触唱片与歌词可在两种视图间切换
- 手动输入局域网地址连接 Mac 菜单栏应用，实时同步歌曲、进度与 `.lrc` / `.lrcx` 歌词
- 首次连接使用 6 位码配对，支持记住设备、断线自动重连

目录、歌曲索引、分组和歌词都只保存在设备本地，没有云端服务。用户输入 Mac 地址并开启连接后，应用会记住地址，并在启动时及断线后自动重连；不会上传音乐文件。

## `.lrc` / `.lrcx` 约定

应用将 `.lrc` 和 `.lrcx` 当作 UTF-8 的时间标签歌词文本，支持：

```text
[ar:音乐人]
[ti:歌曲名]
[00:05.20]第一句歌词
[00:11.850]第二句歌词
[00:18.00][00:42.00]重复出现的歌词
<00:52.00>逐<00:52.20>字<00:52.40>标签
```

歌词与音乐需要同名，例如：

```text
Music/
├── 晚风.flac
└── 晚风.lrcx
```

逐字标签首版会清理标签并按首个时间点高亮整行。如果实际 `.lrcx` 是 JSON、加密文本或其他专用格式，只需扩展
`app/src/main/java/com/xiaoyinzi/player/lyrics/LrcxParser.kt`，其他模块无需修改。

## 构建与运行

1. 使用 Android Studio 打开项目。
2. 安装 JDK 17、Android SDK 35。
3. 等待 Gradle 同步后运行 `app`，或执行：

```bash
./gradlew testDebugUnitTest assembleDebug
```

首次打开会请求通知权限并创建应用专属音乐目录。点击右上角压缩包图标，选择包含 MP3 与同名歌词的 ZIP 文件即可自动导入并扫描。应用不需要“所有文件访问”权限；音乐目录位于应用专属外部存储空间，卸载应用时会一同删除。

## Mac 实时歌词

点击资料库右上角的投屏图标，打开“Mac 实时歌词”。先打开桌面端菜单栏窗口，查看连接地址（例如 `192.168.1.10:49200`），在手机的“手动连接”中输入完整地址，点击连接后再输入 Mac 显示的 6 位配对码。

手机会保存地址并自动重连；Mac 换网或端口变化后，需要重新输入窗口中的地址。两端须处于可互通的局域网。连接功能仅使用手动地址，不进行设备搜索或服务广播。

Android 以本机 `.lrc` / `.lrcx` 为歌词源，Mac 只接收歌曲名、歌词和播放位置，不需要另外准备同名歌词文件。消息格式见 [Mac 实时歌词协议](mac-lyrics-protocol.md)。

## 工程结构

```text
app/src/main/java/com/xiaoyinzi/player/
├── casting/    # 手动连接、配对和实时歌词协议
├── data/       # Room 实体、DAO 与数据库
├── library/    # 目录扫描和资料库业务
├── lyrics/     # .lrc / .lrcx 解析与时间轴模型
├── playback/   # Media3 后台服务和控制器
└── ui/         # Compose 界面与主题
```
